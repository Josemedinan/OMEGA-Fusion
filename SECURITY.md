# Security

This repository contains hardware design sources and verification artifacts; it has no network service. The design is a research/portfolio SoC with **no security features** (no memory protection, no secure boot, no side-channel hardening) and must not be used for security-sensitive purposes.
Report concerns about leaked credentials, private paths or incorrect licensing by opening an issue or contacting the repository owner. Never commit secrets, tokens or proprietary PDK/EDA files.
