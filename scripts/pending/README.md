# Verification tasks that did not fit the 8 GB host

Executable scripts for the open items of `docs/results/PENDING_VERIFICATION.md`. **None of them has been executed to completion** (the PDN-only wrapper stage was the exception, see that document): they are provided so the checks can be run on a machine with ≥ 16 GB RAM and ≥ 60 GB free disk. Each script exits non-zero on failure and writes its evidence under `./pending_results/`. Do not report a result from them as PASS unless the script ran to completion and the log is attached.
